Matte surface finishes

Procedural finishes painted straight into the framebuffer. Each pixel is computed from its position, the display scale and a few parameters, the way the solitaire card backs are drawn. Nothing is baked into a bitmap, and repainting part of the surface gives the same bytes as repainting all of it.

How it is drawn

A finish has a height field in logical units and an albedo change. The painter evaluates two rows of height (the row it is shading and the one below), takes the slope from them and shades it with the theme light, scaled so that a flat patch is exactly the paint colour. Fine detail never gets smaller than one device pixel, so it doesn't alias at any scale. The noise is fixed to the surface's own origin, so a control keeps its finish when it moves and a partial repaint leaves no seams. Memory: the parameters plus two scratch rows the width of the damage.
