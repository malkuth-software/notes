# Agents: start here

1. Read `HOUSE_STYLE.md` in full before writing or changing code.
2. Read the project's own `AGENTS.md`, in its repository. It holds that project's build guardrails.
3. For context on a project, read its branch of this repository (`git worktree add ../notes-<project> <project>`): its plans, decisions, interviews and results.
4. In-house workers also read their desk and track in the private `malkuth-software/projects` repository.

5. Work reaches GitHub through local checkpoints, the default for every project (`template_harness` `docs/workflow.md`): workers commit on local branches and never push, open pull requests or dispatch CI; the coordinator folds their branches, verifies everything CI would reject, and pushes one checkpoint.
