# Decision records

None. No record may be written before Stage 0 closes
(`planning/STAGE_PLAN.md`). The template is in `planning/DECISION_PROTOCOL.md` §2.

Questions expected to need a record, named so they are not decided by accident:

- Who sets the type (interview F010).
- The container format: token unit, formatting model, coder, block size.
- The base Greek and Hebrew texts and the versification master.
- The toolkit consumption model and pin.
- The admitted search channels.
- The expansion source format and evidence rule.
- The paper production method.
- Handling of copyrighted wanted texts.
