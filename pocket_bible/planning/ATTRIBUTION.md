# Attribution: the text of the book's “Sources” page

Stage 1, item 8. Written 2026-10-03. This is the wording the product prints in
its back matter under **Sources**, and the reasoning behind each line. It
covers the rows proposed cleared in `sources/README.md`; a row is added here
when it is cleared and removed if the owner strikes it at gate G1.

The Sources page is not the About section. About opens with the dedication,
exactly as in the root `README.md`, then “Authors: Opus, Fable, Astra,
Rainstar”, with no sponsor line (I49). Sources follows it and never precedes
it.

## What each licence obliges

| Licence | Obligation | How the page meets it |
| --- | --- | --- |
| Public domain | None. Courtesy, and honesty about what was changed | A line naming the edition and the transcriber; “adapted” where the name rule or an importer changes what is shown |
| CC BY 4.0 | Credit the creator; give the licence and a link to it; say whether changes were made; no suggestion of endorsement | A line per work with all four; the changes are listed once, below |
| SIL OFL 1.1 | The copyright notice and the licence travel with the font; Reserved Font Names are not used for modified versions; the fonts are not sold by themselves | The notice is printed here; the licence files ship in the package's `licenses/` directory; the fonts ship unmodified |
| MIT (Ezra SIL's layout tables) | The copyright and permission notice travel with the software | Printed in `THIRD_PARTY_NOTICES.md`, shipped in `licenses/` |

Two requests that are not conditions, and are honoured:

- Berean: “For derivative works that vary from the official text, we
  respectfully request that the Berean name is not used.” The page therefore
  names the BSB as the **source** of the adapted text and does not call the
  adapted text the Berean Standard Bible. The exact title-page wording is the
  owner's (round 003; E005 A gave “BSB, with the divine names rendered by
  rule”).
- eBible.org: “World English Bible” is a trademark and names only the verbatim
  text. The same treatment.

## Notes on the wording

- OBSERVED: the Berean notice is the one on `berean.bible/terms.htm`
  (“appreciated but not required”), copied from `sources/licences/berean-terms.htm`.
  The header of `bsb.txt` carries a longer form that also names unfoldingWord
  and Bible Aquifer; the owner may prefer it.
- The STEP Bible credit follows the form its README asks: credit to “STEP
  Bible”, linked to www.STEPBible.org.
- The font notices are the first lines of each OFL file as saved under
  `sources/licences/`. EB Garamond's file has a second copyright line (2025,
  Deborah Khodanovich, citation glyphs); it travels with the licence file and
  is printed in `THIRD_PARTY_NOTICES.md`.
- Portsmouth has no line because it is not cleared as built
  (`sources/MEASUREMENTS.md` §3). When it returns it needs an OFL file of its
  own naming the owner as copyright holder, beside the source-font notices
  Plan Paint carries. Round 003 asks for the copyright line.
- The King James Version, Swete's Septuagint, the Peshitta and the scanned
  lexica have no line because none is cleared.
- The publication places and dates of the printed books (Charles, Lightfoot,
  Brenton, Strong, Abbott-Smith, Brown–Driver–Briggs) are from general
  reference and from the files' own headers; each is to be checked against a
  title page before the page is typeset.
