# Reading cycles shipped as subjects (U010 A–C)

CANDIDATE list; see `README.md` in this directory. Nothing fetched. A reading
cycle is a table of references: the divisions themselves are tradition and
fact, and carry no copyright; a particular published table may. Every table
below is rebuilt from a public-domain printing or from the text itself, and
each reference is checked against the stored versification before it ships.

A subject in this book is a named set of passages with a tab (G13, N013–N016).
A cycle is a subject whose passages have an order and, for A and B, a date.
The book has no clock of its own beyond the system date; whether a cycle shows
“this week's reading” is a Stage 6 question (round 003).
