Where T3 stands

Round 1 is recorded in the T3 brief: CSS property names lowered onto engine parameters plus engine names for what CSS lacks; shorthands; px, percentages and em; colour roles first; theme variables with engine inputs read-only; :is(); themes compiled, where unknown properties warn and bad values refuse the theme; transitions and keyframes on published states; one sheet with @media; @import by name; a JSON manifest; inline styles from C++ and form documents with your !important rule, high contrast still winning on colour; the hostile-input limits; the parser internal until stage V.

The plan found six engine changes T3 needs, each its own phase. The biggest: the material primitive takes only a recipe and a shape, so CSS backgrounds, borders and shadows have nothing to land on yet. Colour roles don't exist in code yet either. Plan size: 11 phases, about 20 to 24 PRs.
