# GUI.Forms notes

This is the `gui_forms` branch of `malkuth-software/notes`: everything about GUI.Forms that is worth keeping but isn't needed to build it.

| Folder | What |
|---|---|
| `planning/` | the forward programme, stage briefs and plans (`planning/stages/`), the design language, the house-style copy, and ROADMAP_TO_0.5 |
| `decisions/` | architecture decision records |
| `interviews/` | the owner's interview pages and answer files, per stage |
| `studies/` | design and engineering studies, with their specimen images |
| `experiments/` | experiment reports and data |
| `results/` | gate records and measurements |
| `docs-notes/` | working notes formerly in `docs/notes/` |

Copied from gui_forms main at the `checkpoint-2026-10-27` tag (14164ee5), plus the interviews and studies held on the coordinating machine. gui_forms' own history still has the originals. From now on, these are maintained here, not in gui_forms.
