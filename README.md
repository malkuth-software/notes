# Pocket Library notes

This is the `books` branch of `malkuth-software/notes`. It holds everything about
Pocket Library (`malkuth-software/books`) that is worth keeping but isn't needed to
build it.

| Folder | What |
|---|---|
| `pocket_bible/` | Pocket Bible, the planning-stage predecessor of Pocket Library, archived by the owner on 2026-10-27 |

Pocket Library's own planning, decisions, studies and results will join this branch
in the same layout as the `gui_forms` branch (`planning/`, `decisions/`, `studies/`,
`experiments/`, `results/`, `docs-notes/`).

## pocket_bible/

Pocket Bible (`falseywinchnet/pocket-bible`, private) planned a fully offline Bible on
GUI.Forms through interviews and stages from 2026-10-03 to 2026-10-04. Pocket Library
grew from PlaySuite's shell separately, from 2026-10-19, and shares no history with
it. The files here are copied unchanged from the pocket-bible branches named below.

| Folder | What | From |
|---|---|---|
| `planning/` | charter, invariants, stage plan, protocols, reconciliations 001 to 003, the source register, proposals, stage handoffs and stage reports (Stages 0 to 4) | `planning/` on `work/s4-page` (`0097e89`), which is `main` (`5c2b5f3`) plus the Stage 4 report |
| `planning/continuation/` | where Stages 3 and 4 stopped | `astra/` on `work/continuation-notes` (`5ad01c8`) |
| `decisions/` | the decision index (no record was accepted) | `decisions/` |
| `experiments/s3-container/` | Stage 3: fallback originals, the text study, the container candidates | `experiments/` on `work/s3-container` (`72eba7a`) |
| `experiments/s4-page/` | Stage 4: page routes, passage fixtures, the proving slice, shaped marks | `experiments/` on `work/s4-page` |
| `docs-notes/` | the toolkit requests Pocket Bible recorded for GUI.Forms | `docs/TOOLKIT_REQUESTS.md` |

The interviews are private and are not on this branch: the interview pages, the
owner's answer files (`planning/interview/`), their transcriptions
(`planning/ARCHITECTURE_INPUTS*.md`) and the owner's verbatim brief and direction
(`planning/OWNER_*.md`). Documents here that cite those files refer to that private
archive. The code (importers, the container, the page proving slice) and the
normalized sources stay in `falseywinchnet/pocket-bible`.
