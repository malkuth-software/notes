# SwiftEdit notes

This is the `swiftedit` branch of `malkuth-software/notes`. It holds everything about SwiftEdit (`malkuth-software/swiftedit`) that is worth keeping but isn't needed to build or use it.

| Folder | What |
|---|---|
| `planning/` | the objectives ledger from the owner's 2026-09-30 interview (`SWIFTEDIT_OBJECTIVES.md`), the implementation tracker, known gaps, and the restart and macOS build handoffs |
| `decisions/` | the historical decision record and the prepared-shaping storage decision |
| `studies/` | reviews and proposals: prepared batch, shaping, window controller and workspace reviews, the print contract review, the house-style audit, picker file-link adoption, and the SDK aaca5d0 intake |
| `results/` | validation records, the 2026-10-07 build validation, the 2026-10-01 dogfood, native visual evidence, document scrollbars, release verification receipts (`releases/`) and visual captures (`visual/`) |
| `experiments/` | measured performance runs: `docs-performance/` (formerly `docs/performance/`) and `performance/` (formerly the top-level `performance/`) |

Copied unchanged from swiftedit `master` at the reset root `05c2bd9` (2026-10-27). Links inside these files still use their old `docs/...` paths. SwiftEdit's own repository keeps what builds, packages or documents the product for users: `README.md`, `AGENTS.md`, the command protocol (packaged with the macOS app), the terminal and encoded-session documents, the build architecture, automatic releases, document-view fixtures, the release notes (`docs/releases/v*.md`, read by `tools/Publish-Release.py`) and the house-style copy. From the commit that removes these files from SwiftEdit onward, they are maintained here.
