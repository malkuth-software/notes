# PlaySuite notes

This is the `games` branch of `malkuth-software/notes`: material about PlaySuite (`malkuth-software/games`) that is worth keeping but isn't needed to build it.

| Folder | What |
|---|---|
| `records/` | native run logs, screenshots and state from the 2026-10-01 refinement and Windows hand-off (formerly `evidence/` in the product) |
| `proposals/` | proposals PlaySuite made to GUI.Forms: the accessibility request and the reusable controls proposal (formerly in `docs/`) |

Copied from games main bc229b8 (the 2026-10-27 root). The working list of open GUI.Forms requests, `docs/TOOLKIT_REQUESTS.md`, stays in the product, because its AGENTS.md rules point to it. From now on, interviews, decisions and studies about PlaySuite are kept here, not in the product.
